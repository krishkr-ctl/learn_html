Build your first web page, tag by tag.

This page teaches HTML and CSS the way you'll actually use them: a short explanation, the exact code, and the live result sitting right next to it. Read top to bottom, or jump to any topic in the menu.

Start learning ↓
What is HTML, really? HTML (HyperText Markup Language) describes the content and structure of a page — this is a heading, this is a paragraph, this is a picture. CSS (Cascading Style Sheets) describes how that content looks — colors, spacing, layout. Together they build almost every web page you've ever visited.
Part one

HTML — structuring content

01

Document structure

Every HTML file starts with the same skeleton. <!DOCTYPE html> tells the browser which version of HTML you're using. Everything visible lives inside <body>, while page information like the title lives in <head>.

index.html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
  </body>
</html>
My First Page

Hello, world!

Notice the pattern: most tags come in pairs, an opening tag <h1> and a closing tag </h1>, wrapping the content between them.

02

Headings & paragraphs

Headings range from <h1> (most important, use once per page) down to <h6> (least important). Regular text goes inside a <p> paragraph tag.

index.html
<h1>Main Title</h1>
<h2>A Subheading</h2>
<p>This is a normal
  paragraph of text.</p>
output

Main Title

A Subheading

This is a normal paragraph of text.

03

Text formatting

A handful of tags change how text reads: <strong> for importance (bold), <em> for emphasis (italic), <br> for a line break, and <hr> for a horizontal divider.

index.html
<p>
  <strong>Warning:</strong>
  don't forget to save.<br>
  <em>Seriously.</em>
</p>
<hr>
output

Warning: don't forget to save.
Seriously.

04

Links

The anchor tag <a> creates a clickable link. The href attribute holds the destination address, and target="_blank" opens it in a new tab.

index.html
<a href="https://example.com"
   target="_blank">
  Visit Example
</a>
output
Visit Example
05

Images

The <img> tag has no closing tag — it's self-closing. It needs src (where the image file is) and should always have alt text describing the image, for accessibility and for when the image fails to load.

index.html
<img
  src="mountain.jpg"
  alt="Sunrise over a mountain range"
  width="260">
output

src can point to a file in your own project folder (like images/mountain.jpg) or to an address on the web, as shown above.

06

Lists

Use <ul> for a bulleted (unordered) list, or <ol> for a numbered (ordered) list. Each item goes inside an <li> tag.

index.html
<ul>
  <li>Flour</li>
  <li>Sugar</li>
</ul>

<ol>
  <li>Preheat oven</li>
  <li>Mix batter</li>
</ol>
output
  • Flour
  • Sugar
  1. Preheat oven
  2. Mix batter
07

Tables

<table> holds rows (<tr>), which hold cells: <th> for a header cell, <td> for a regular data cell.

index.html
<table>
  <tr>
    <th>Name</th>
    <th>Score</th>
  </tr>
  <tr>
    <td>Amina</td>
    <td>92</td>
  </tr>
</table>
output
NameScore
Amina92
08

Forms

Forms collect input. A <form> wraps fields like <input>, <select>, and a submit <button>. Always pair an input with a <label> so screen readers and click targets work properly.

index.html
<form>
  <label>Your name</label>
  <input type="text"
    placeholder="Jane Doe">

  <label>Favorite color</label>
  <select>
    <option>Blue</option>
    <option>Green</option>
  </select>

  <button>Submit</button>
</form>
output
09

Divs & semantic tags

<div> is a plain, meaning-free box used to group things for styling. Modern HTML also offers semantic tags that describe the role of a section — <header>, <nav>, <main>, <section>, <article>, and <footer> — which help browsers, search engines, and screen readers understand your page.

index.html
<header>
  <h1>My Blog</h1>
</header>
<main>
  <article>
    <h2>A Post</h2>
    <p>Some text.</p>
  </article>
</main>
<footer>© 2026</footer>
output
My Blog
A Post
Some text.
© 2026
10

Attributes & comments

An attribute adds extra information to a tag, written as name="value" inside the opening tag — you've already seen href, src, and alt. A comment is a note in your code that the browser ignores; it's written <!-- like this -->.

index.html
<!-- This is the top banner -->
<div id="banner" class="highlight">
  Sale ends tonight!
</div>
output
Sale ends tonight!

id names one unique element; class can label many elements that should share a style — both become hooks for CSS, which is exactly what's next.

Part two

CSS — styling that content

11

Three ways to add CSS

You can write CSS inline on one element, internally in a <style> block in the head, or externally in a separate .css file linked with <link>. External files are the standard choice for real projects, because the styling stays separate from the content.

index.html
<!-- 1. inline -->
<p style="color:teal">Hi</p>

<!-- 2. internal -->
<style>
  p { color: teal; }
</style>

<!-- 3. external -->
<link rel="stylesheet"
  href="style.css">
output

Hi

All three methods can produce the same teal text — they just differ in where the rule lives.

12

Selectors

A CSS rule is a selector plus a set of declarations. Target every element of a type with its tag name, a specific one with #id, or a group with .class.

style.css
p {
  color: #20232A;
}

.highlight {
  background: gold;
}

#banner {
  font-weight: bold;
}
output

Every p gets this color.

.highlight class

#banner id (bold)

13

Colors & backgrounds

Colors can be named (teal), hex codes (#1F5B4F), or rgb() values. background-color fills the element, color sets the text.

style.css
.card {
  background-color: #1F5B4F;
  color: white;
  border-radius: 8px;
  padding: 16px;
}
output
A styled card
14

The box model

Every element is a rectangular box made of four layers, from the inside out: content, padding (space inside the border), border, and margin (space outside the border, pushing other elements away).

style.css
.box {
  width: 160px;
  padding: 14px;
  border: 4px solid #1F5B4F;
  margin: 20px;
}
output
content

tan = margin, green border = the border, white gap = padding

15

Styling text

Common text properties: font-family, font-size, font-weight, and text-align.

style.css
h2 {
  font-family: Georgia, serif;
  font-size: 24px;
  font-weight: 700;
  text-align: center;
}
output

Centered Heading

16

Flexbox

display: flex lines up a container's children in a row (or column) and makes spacing between them easy — perfect for navigation bars and card rows.

style.css
.row {
  display: flex;
  gap: 10px;
}
.row div {
  flex: 1;
}
output

2
3
17

Grid

display: grid lays children into rows and columns at once. grid-template-columns defines how many columns and how wide each is.

style.css
.gallery {
  display: grid;
  grid-template-columns:
    1fr 1fr 1fr;
  gap: 8px;
}
output

18

Responsive design

A media query applies CSS rules only when a condition — usually screen width — is met. This is how the same page adapts from desktop to phone.

style.css
.row {
  display: flex;
}

/* on narrow screens */
@media (max-width: 600px) {
  .row {
    flex-direction: column;
  }
}
output

This very page uses that trick — try resizing your browser window and watch the left menu turn into a "☰ Course Menu" button.
